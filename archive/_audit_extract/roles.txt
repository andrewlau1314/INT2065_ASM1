一、先一起定死的範圍（全員，第一次會議）
對象：中五或中六，選修 Option C Algorithm and Programming，已懂一維陣列。
一課只比較三種結構如何加入和移除，每種只走一個操作：
Stack：push，學生看 top。
Queue：enqueue，學生看 front 和 rear。
Linear linked list：在指定位置 insert，學生看 head 和 next。
公開試要的是用陣列模擬，不是 Python 的 append / pop，也不是真正的 pointer。pop、dequeue、delete 和學生自己寫完整程式，放到下一課，不放進這份教案。
二、成員 A：教案
寫完整教案：課題、對象、先備知識、學習目標、時間分配、教學流程、差異化、評估。
寫教學法依據：用同一張陣列圖比較三者，每種結構只演示一個操作，避免學生混淆 top、front 和 next。
根據成員 C 的說明，把「為何選這個工具」寫進教案。
對照《課程及評估指引》選修 C 的用字：lists, stacks and queues in terms of arrays。
三、成員 B：工作紙
學生工作紙只用全員定好的那一組數字。
三題逐步追蹤：push、enqueue、insert。每步要學生寫出陣列和指標。
附教師答案，答案不印給學生。
可加一題課後延伸，但註明不在這節課完成。
題目分量必須是一節課做得到的。
四、成員 C：可視化工具
做一個逐步視覺化工具。學生按「下一步」，畫面顯示 top、front、rear 或 next 的改變。
寫一頁系統設計：畫面有什麼、學生怎樣操作、哪一部分用了人工智能。用了就要寫明；如果只是動畫，就不要說成人工智能。
用要點寫出「為何選這個工具」，交給成員 A 放進教案、交給成員 D 放進簡報。
工具裡的數字必須和工作紙相同。
五、成員 D：簡報、可行性、倫理
做簡報和講稿，控制全組 10 分鐘，並預留 5 分鐘問答。
寫三段內容：教育價值、可行性、倫理和社會影響。
可行性要面對真實限制：一節課、學校電腦室、工具不必安裝複雜軟件。
倫理要包括：老師核對人工智能產出；學生要用圖解釋答案，不能只抄工具或聊天機械人的結果。可引用教育局 2026 年《人工智能素養學習框架》。
彙整參考資料，以及小組使用人工智能的聲明。
合併最終檔案，提醒全員截止日期。

1. Scope the whole group must lock in the first meeting
Level: S.5 or S.6, Elective Option C Algorithm and Programming, students who already know one-dimensional arrays.
One lesson only compares how the three structures add and remove data. One operation each:
Stack: push. Students watch top.
Queue: enqueue. Students watch front and rear.
Linear linked list: insert at a given position. Students watch head and next.
The public assessment expects an array simulation, not Python append / pop, and not real pointers. pop, dequeue, delete, and students writing full programs belong in the next lesson. Leave them out of this lesson plan.
2. Member A — lesson plan
Write the full lesson plan: topic, level, prior knowledge, objectives, timing, procedure, differentiation, assessment.
Write the pedagogical ground: one array diagram is used to compare the three structures, and only one operation is demonstrated for each, so students do not mix up top, front and next.
Using Member C's notes, write "why we chose this tool" into the lesson plan.
Match the wording of the ICT C&A Guide, Elective C: lists, stacks and queues in terms of arrays.
3. Member B — worksheet
Use only the example the group agreed.
Three step-by-step traces: push, enqueue, insert. At each step the student writes the array and the pointers.
Provide a teacher answer key. Do not print it for students.
One extension item may be added if it is marked as homework, not as classwork for this lesson.
The worksheet must be finishable in one lesson.
4. Member C — visualisation tool
Build a step-by-step visualiser. Each click on "next" shows the change in top, front, rear or next.
Write a one-page system design: what is on screen, what the student does, and which part uses AI. If a part uses AI, say so. If a part is only animation, do not call it AI.
Draft bullet points on why this tool was chosen. Pass them to Member A for the lesson plan and to Member D for the slides.
The numbers in the tool must be the same as the numbers on the worksheet.
5. Member D — slides, feasibility, ethics
Build the slide deck and speaker notes. Keep the group to 10 minutes, and leave 5 minutes for questions.
Write three sections: educational value, feasibility, ethical and social implications.
Feasibility must face real limits: one lesson, a school computer room, and no complicated installation.
Ethics must include: the teacher checks any AI output; students explain answers from the diagram and do not copy the tool or a chatbot. The EDB AI Literacy Learning Framework (2026) can be cited.
Compile references and a short statement of how the group used AI.
Merge the final files and remind the group of the deadline.
6. Cross-check
A checks B: the worksheet does not go beyond one lesson.
B checks C: the tool uses the same example as the worksheet.
C checks D: the system described on the slides matches the real tool.
D checks A: the lesson objectives appear on the slides.
7. Who answers questions
Curriculum and objectives: Member A.
Worksheet items: Member B.
Tool and system: Member C.
Feasibility and ethics: Member D.
All four stay for the Q&A. If a question is outside your part, take it in one sentence, then hand it to the owner.
