# INT2065 ASM1

Assignment 1 materials for INT2065: a lesson on adding an item to a stack, a queue, and a linked list, with a classroom visualiser.

**Published site:** https://andrewlau1314.github.io/INT2065_ASM1/

That address opens the stack, queue, and linked list visualiser. The root page redirects to `visualiser/index.html`.

**Practice quiz:** [https://andrewlau1314.github.io/INT2065_ASM1/quiz/](https://andrewlau1314.github.io/INT2065_ASM1/quiz/)

A short student practice set on adding an item to a stack, a queue, and a linked list. It is not an official examination paper.

## In this repository

- Lesson plan, worksheet, presentation, and group-role notes (`*_REFINED` files and `小組分工_中英.docx`)
- Student quiz and teacher answer key
- `visualiser/` — the interactive visualiser published on GitHub Pages
- `quiz/` — the student practice quiz published on GitHub Pages
